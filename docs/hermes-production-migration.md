## 3. Procedure (each step reversible; you can stop after any step)

0. **Backup** (read-only on Hermes): `hermes-migrate.py bundle --source %LOCALAPPDATA%\hermes --out F:\Odysseus-Backups\hermes-bundle-<date> --python <Hermes python>` (about 17 s, 74 MB). It is also the restore copy of your data. Also run the existing full Odysseus backup and note its `verify`.
1. **Review**: `inventory --markdown` and `manifest.json` (what was carried, what was not).
2. **GATE: dependency** (change 1).
3. **GATE: install the managed component** (change 2); this creates the empty managed home. Do not start the gateway.
4. **Plan**: `hermes-migrate.py plan --bundle ... --root ...` must report `problems: []` (empty home, gateway stopped, not the source).
5. **GATE: apply**: `apply --bundle ... --root ... --confirm-target <managed home>`. A zip of the managed home is written first to `<root>\migration\backups\pre-migration-*.zip`. The tool can only write the managed home; there is no option to name another folder.
6. **Verify**: `verify --bundle ... --root ...` (counts and per-file hashes).
7. **Credentials**: nothing to set for Hermes itself. Enter `OPENCODE_ZEN_API_KEY` again if you use those models. Claude and Codex are allowed at step 5 and keep their logins where they already are. (An earlier version of this runbook said to set a Hermes password; that was wrong for this setup.)
8. **Rehearse off to the side**: a second Odysseus on a spare port with `ODYSSEUS_HERMES_BACKEND=webapp`; open Projects, one migrated conversation, a scratch-repo Git commit; stop it. Set `HERMES_WRITE_SAFE_ROOT` to your real project folders (your action) and check a Btrfs folder against the guard first.
9. **GATE: switch** (changes 3 and 4). Check on `localhost:7000`: Personal works, Projects starts Hermes, chat and a commit work, Services shows managed controls, Odysseus logout ends Projects access.
10. **Keep the old WebUI** on 8787 for a trial period; retire it only on your word.

## 4. Rollback

| Situation | Action |
|---|---|
| Before step 3 | nothing changed except the backup |
| After apply, before switching | `rollback --root ... --safety-copy <pre-migration zip> --confirm-target <managed home>`: the migrated home is moved aside (never deleted). *Live drill:* the home matched its pre-migration config exactly |
| After switching | remove the User variables and restart; Projects shows the old WebUI again. The old home was never written |
| Data question | the step 0 bundle restores your data independently; the grant database is intentionally not restored |
