What can and cannot be shared

  • Shareable: local OpenAI-compatible servers (llama.cpp, vLLM, LM Studio, Ollama) and keyed cloud endpoints. The provider definition is copied; a key is not.
  • Needs a key on the other side: a shared cloud provider appears as "Needs authentication" until you enter its key in that application.
  • Never shared: OAuth and subscription logins (Codex, Copilot, Nous, Claude subscription), which are tied to one application.
  • Removing a provider in one application never removes it in the other, and a provider you remove is not added back unless you turn sharing on again.
